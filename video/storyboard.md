# 動画の段取り（収録 → 編集 → 字幕）

提出要件: 1〜3分、倍速は2倍まで・明記、MP4、YouTube限定公開以上、氏名等を映さない。タイトルは `PAI最終課題_<omnicampusアカウントID>`（IDは未取得）。

## 方針
- 収録は **コンテナの画面だけ**（Gazebo GUI + HUD端末）。通知・タスクバー・個人情報は映らない。計画(LLM)から実行(Gazebo)まで一続きで撮る（`video/record_exec.sh ... live`）。
- LLMの待ち時間（現状 約1〜1.5分/回）は編集で詰め、**詰めた箇所は字幕で明記**する（例「LLM推論 87秒（待機を省略）」）。実行シーンは等倍か2倍速（字幕に自動で「2倍速」が付く）。
- 構成図・結果・まとめは静止画カード（`video/make_cards.py`）。

|---|---|---|---|---|

合計 約2分〜2分30秒（上限3分）。

## 手順（私が実行する）
1. 前準備: `powershell -File /tmp/trim.ps1` 相当で待機アプリのメモリを退避し、`sim/scripts/mem_guard.py` を並走（空き0.35GB未満が8秒続いたらモデルを解放）。
2. 各シーン: `docker exec pai-sim bash /pai-final/video/record_exec.sh <名前> "<指示>" live`（毎回シミュレーターを再起動して原点から開始、`video/raw/<名前>.mp4`）。
3. 素材の確認（フレームを抜き出して、文字化け・映り込みがないことを目視）。
4. `video/make_cards.py` でカードを作り、`video/edit_list.json` に切り出し区間・倍速・字幕を書いて `python -X utf8 video/assemble.py` で `video/out/final.mp4` を作る。
5. 提出前チェック: 長さ(1〜3分)、倍速・省略の字幕、個人情報なし、恒久フォルダへ受領票つきで配置（AGENTS.md の可視成果物ゲート）、YouTube公開はあなたの承認後。
